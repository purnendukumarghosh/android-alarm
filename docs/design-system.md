# Voice Alarm — "Monoline" design system

Minimal and calm, like a watch face at night: thin white line icons and
hairline shapes on a near-black sky with a few faint stars. There are no
gradients, glows or bevels. Emphasis comes from type size and line
brightness, and color only ever signals state. Everything is drawn in code
(the illustrations and launcher icon are vectors generated by
`tools/art/line_art.py`), so it is sharp on every screen.

Framework-only Android views (no AndroidX), Kotlin, minSdk 26, targetSdk 34.

## Tokens (`ui/Neon.kt`, `res/values/colors.xml`)

Token names are historical (from the earlier neon theme); the values are
what matter.

| Token | Value | Use |
| --- | --- | --- |
| `BG0` / `BG1` / `BG2` | `#050608` / `#0A0B0F` / `#121419` | backdrop, bars, sheets |
| `SURFACE_TOP` / `SURFACE_HI` | `#0D0E12` / `#15171C` | card plane / raised plane (snackbar, selected row) |
| `LINE` / `LINE_STRONG` | white 14% / white 80% | resting hairline / selected or focused line |
| `CYAN` (= primary) | `#F2F3F5` | primary lines and active states are plain white |
| `RED` | `#FF5D6C` | ringing, delete, recording, the clock's second hand |
| `AMBER` | `#F0C46C` | "needs attention" |
| `GREEN` `BLUE` `VIOLET` `MAGENTA` | muted | rarely used; icons tinted with them collapse to white |
| `TEXT1` / `TEXT2` / `TEXT3` | `#F2F3F5` / `#9A9DA6` / `#5F626B` | primary / secondary / muted text |

`Neon.lineTint(color)` keeps icons monochrome: any saturated tint becomes
white except the signal colors red and amber. `Context.icon()` applies it.

## Type (`res/values/themes.xml`, font: Manrope)

`Text.Display` (64sp extralight, big times and numbers) · `Text.Headline`
(26sp light) · `Text.Title` (18sp medium) · `Text.Body` (15sp regular, TEXT2)
· `Text.Caption` (12sp medium, TEXT3) · `Text.Overline` (11sp semibold,
tracked caps, TEXT3: section headers) · `Text.Button` (15sp semibold).
`TextView.neonText()` is now a no-op that resets text to plain `TEXT1`.

## Surfaces (`ui/Depth.kt`)

All are `DepthDrawable`s that reserve a little room around the body, which
doubles as spacing between neighbours. **Always apply with
`view.depthBackground(drawable)`**, which adds that room to the padding.

| Drawable | Look | Use |
| --- | --- | --- |
| `GlassCardDrawable(ctx, radius, topColor, outline?, pressable)` | flat plane + 1dp hairline; `outline != null` = bright white line (selected); `topColor = 0` = outline only | cards, chips, pills, selected rows, sheets |
| `NeonButtonDrawable(ctx, colors, radius = -1 pill)` | outlined pill: white (primary), red (`FLAME`), grey (other); faint wash when pressed | buttons |
| `SphereDrawable(ctx, color, glow)` | a single thin circle; `glow` = whisper fill; `base` = opaque disc behind it | "+" button, record button, selected day, avatar badge, logo |
| `SunkenDrawable(ctx, radius, active)` | hairline well that turns bright when focused/active | text fields, segmented control |
| `GlowBackgroundDrawable(accent?)` | near-black sky, faint deterministic stars, soft horizon haze (red on the ringing screen) | root background of every screen |

## Layout rules

- 8dp grid. Screen gutter 20dp. 20dp between sections, 12dp inside.
- Touch targets ≥ 48dp. Primary buttons 56dp tall, pill-shaped, full width in footers.
- Card radius 22dp; chips/pills fully rounded; inputs 16dp.
- Section = overline header (`Text.Overline`) + hairline card with content.
- Icons: Material Symbols Rounded **weight 200 outlines**, `@drawable/ic_<name>`
  (the `_fill` names are kept as aliases and are outlines too). Row icons sit
  inside a faint thin ring (`iconTile`).
- Selected / ON = brighter white line, never a glow. One signal color per
  element at most.
- Motion: 180–260 ms, `DecelerateInterpolator` in / `AccelerateInterpolator` out;
  presses respond instantly (drawable state), knobs/indicators animate.
- Accessibility: every icon-only control has `contentDescription`; custom
  controls announce role/state (`AccessibilityNodeInfo` class name of
  Switch/SeekBar/Button) and support `performClick`; text contrast ≥ 4.5:1.

## App structure

- **MainActivity** — the shell: `NeonDrawerLayout` (hamburger side drawer with
  content tilt), `AppBar` (hamburger, title/subtitle, actions), a page
  container and a `BottomNavBar` dock of line icons around a "+" drawn as a
  thin circle. Pages (`ui/Page.kt`): **Alarms**, **Nap** (quick naps), **Voices**
  (voice studio), **Settings**. Intent extras: `EXTRA_START_TAB`
  (`"alarms" | "nap" | "voices" | "settings"`), `EXTRA_OPEN_DRAWER` (Boolean).
- **AlarmEditActivity** — sectioned editor with a sticky footer Save button;
  extra `EXTRA_ID` (Int, -1 = new).
- **AlarmRingActivity** — full-screen ringing screen with an live line-art clock,
  slow hairline ripples, voice visualizer and slide-to-dismiss; extras
  `AlarmService.EXTRA_ALARM_ID`, `EXTRA_PREVIEW` (Boolean, shows the screen
  without a ringing alarm — used by "Test alarm screen" and screenshots).
